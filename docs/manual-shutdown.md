# 裝置配對與手動關機（v800）

WebDAV 可匿名使用。關機使用獨立裝置配對，不依賴 WebDAV 帳密，也不需要 setup_power.sh 或手動複製關機憑證。

電腦需更新到 power5 或相容版本，在 Server 設定開啟「允許裝置配對（首次需在電腦批准）」與「允許已授權腳本請求關機」。這些設定只需做一次；不需建立或複製舊版關機授權。HTTP 僅使用已設定的私人 IPv4 區網，外網使用驗證憑證的 HTTPS。

首次使用時，Dex 在 root 私有目錄產生裝置金鑰，向支援配對功能的 SpeedBackup Server 提出請求。使用者在電腦原生視窗核對完整指紋並批准這台裝置一次（管理網頁也可批准／撤銷）；後續自動以金鑰簽章完成握手，取得僅限本次任務的短效憑證。短效憑證僅保留於 Dex 記憶體，不交給 Shell、命令列或除錯包。

裝置金鑰目錄為 `/data/adb/speedbackup-power`，0700；私鑰檔案 0600。備份封裝排除此目錄。刪除金鑰、重設 Server 或撤銷裝置後才需重新配對。一般 WebDAV 不支援此功能。首次批准最多等待 120 秒，逾時本次不發送；手機與 Server 都保留裝置身分，之後無需重複設定。

每次備份／恢復完成收尾後，不論成功、失敗、部分完成或正常取消，音量上才要求關機；音量下或 30 秒未選擇即略過。仍在工作的程序、目的地主機改變、能力或配對驗證失敗時不發送。強制终止或斷電不會於下次啟動自動補送。

Server 接受請求不等於已關機。電腦端仍可取消或延後；通知結果不修改原備份／恢復返回碼。

由 v799 覆蓋更新時，可刪除舊 setup_power.sh；v800 不再提供或呼叫它。已有 config.json 舊授權不再讀取，無需將它轉換成新配對。
