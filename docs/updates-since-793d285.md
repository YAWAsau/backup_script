# v1102 → v1117 更新內容

比較基準：[793d285 — Update README.md](https://github.com/YAWAsau/backup_script/commit/793d285d6c2ee035615b58e10f8abae19cf50947)。該提交的 `versions.properties` 為 v1102；本次整理截至 v1117，原生介面為 1.75（versionCode 76）。本文件描述本地已完成的交付內容，不代表已推送或發布 GitHub Release。

## 自動發現電腦與 NAS

- 設定新增 WebDAV／SMB 自動發現與地址追蹤開關，保留手動輸入；同一設備有多個地址時可選擇。
- 首次使用自動地址時選擇設備，再填寫帳號、密碼及必要的共享路徑；按「連線並繼續」儲存到 conf。
- 下次優先驗證已選設備；確認同一設備只是 IP 改變時，提示並更新地址，保留帳密與路徑。找不到原設備才重新選擇，傳輸中不更換目的地。
- Rust 使用 DNS-SD 與 SMB ServerGuid 辨識設備，支援無廣播的 SMB 探測；搜尋結果逐批呈現。WebDAV 廣播需要伺服器支援，既有 Windows／NAS SMB 分享不需更換伺服器。
- 修正已選地址下次仍要求重選、設備識別受 JSON 欄位順序影響，以及 Android 多播鎖生命週期問題。
- 發現設備不會自動開始備份或恢復，仍由使用者啟動操作。

## 遠端登入與連線頁

- WebDAV 401、SMB 明確認證拒絕時提供帳號／密碼重填、儲存並重試或返回；遠端編輯亦先驗證認證。
- 網路、路徑及權限錯誤與認證失敗分開處理，不自動重播上傳或刪除。
- 自動發現後只顯示所選協定的連線欄位，移除重複的還原／儲存操作，統一由底部「連線並繼續」保存。一般備份設定仍保留完整選項。

## 繁簡語言與轉換

- 切換語言後儲存設定並自動重新載入腳本；工作進行中延後至安全收尾，不重跑備份／恢復。
- 首頁資訊改以固定識別碼分組，繁簡使用相同分類與順序；補齊通知、接回提示、壁紙與鳴謝說明的語言處理。
- Dex 轉換維持每檔一次啟動與串流處理，增加緩衝及 ASCII 快速路徑，輸出失敗回傳非零狀態。
- 加入 OpenCC 1.4.2 的 49,715 條繁簡詞組，改善髮／發、乾／干、后／後等選字；保留原本產品用詞，不新增原生 OpenCC ELF 或 JNI。
- 正式腳本使用版本對應的完整行還原表，避免繁簡往返累積差異；建置時自動生成及驗證，移除手動逐條補表的需求。自行修改或其他版本未收錄的行不保證無損。
- 保護應用角色辨識的繁簡正則，避免翻譯改壞兩種字形的匹配。

## 診斷與後端整理

- 同一工作服務階段的操作合併成單一 debug tar，包內使用單一根目錄與連續日誌，避免大量 run 子目錄；JSON 保留最新有效內容與歷史索引。
- 診斷歸檔使用阻塞鎖與原子發布，移除 sleep 輪詢與多餘的大小穩定等待；鎖取得仍有 5 秒逾時，失敗保留原包及日誌。
- conf 解析、舊欄位補全、原子保存、地址追蹤、帳密重填協調及 SMB 錯誤分類移至 Rust；通知文字、進度校正與分類集中 Dex。
- 移除已被替代的 Shell 實作，保留備份／恢復流程與傳輸介接。
